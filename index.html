Fantasy Championship Manager 2026/27

Project & Photo Credits

Fantasy Championship Manager 2026/27 is a fan-made head-to-head league viewer styled after classic early-2000s football-management games. The background library deliberately uses English grassroots, Sunday-league and local-football imagery rather than recognisable professional-club photography.

Project

  • Concept, direction and website project: Cathal Doyle
  • Prototype build and iterative refinement: ChatGPT
  • Website: cathaldoyle.com
  • Source code on GitHub
